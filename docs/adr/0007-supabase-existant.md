# ADR 0007 — Projet Supabase existant réutilisé

Date : 2026-11-23 · État : acceptée

## Décision

Le nouveau jeu utilise le projet Supabase déjà créé. Les anciennes tables de sauvegarde sont retirées à la bascule.

## Pourquoi

Garder les comptes et les réglages de connexion déjà faits.

## Conséquences

Les parties en ligne du brouillon sont effacées à la bascule ; les comptes sont conservés.
