# ADR 0010 — zod pour valider les données et les ordres

Date : 2026-11-23 · État : acceptée

## Décision

Le paquet `data` utilise zod pour valider l'équilibrage, la table de déblocage et les ordres
envoyés par le joueur. Le moteur (`core`) n'importe pas zod : il reçoit des données déjà validées.

## Pourquoi

Un seul schéma sert à trois choses : refuser une donnée d'équilibrage invalide, donner ses types
au code, et valider côté serveur tout ce que le client envoie.

## Conséquences

zod est la seule bibliothèque de `data`. Le schéma des ordres est partagé par le client et le serveur.
