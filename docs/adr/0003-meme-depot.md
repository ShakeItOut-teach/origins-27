# ADR 0003 — Même dépôt, nouvelle branche principale

Date : 2026-11-23 · État : acceptée

## Décision

Le nouveau jeu vit dans le dépôt existant. Le brouillon est conservé dans la branche archive/brouillon-v1. Le travail se fait sur next, qui remplacera main à la bascule.

## Pourquoi

Garder l’adresse, l’historique et les avis reçus.

## Conséquences

Le site actuel est remplacé à la bascule. D’ici là, main n’est pas touchée.
