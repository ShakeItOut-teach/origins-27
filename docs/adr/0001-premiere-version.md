# ADR 0001 — Première version : paliers 0 à 2, déjà sur serveur

Date : 2026-11-23 · État : acceptée

## Décision

La première version jouable contient les paliers 0 à 2 (cellule, organites, première mutation), avec compte et état calculé côté serveur.

## Pourquoi

Poser le socle multijoueur avant d’empiler les mécaniques ; le brouillon a montré qu’ajouter le serveur après coup oblige à tout réécrire.

## Conséquences

Peu de contenu au début, mais fini. Les paliers suivants ont chacun leur plan.
