# ADR 0008 — Déploiement sans accord préalable

Date : 2026-11-23 · État : acceptée

## Décision

Les agents déploient dès que toutes les vérifications passent, puis contrôlent le site en ligne. En cas d’échec, retour à la version précédente d’abord.

## Pourquoi

Le propriétaire veut une boucle rapide, sans question à chaque mise en ligne.

## Conséquences

Restent soumis à accord : ressource payante, effacement de données de joueurs, ancien site.
