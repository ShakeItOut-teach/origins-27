# client — ce que le joueur voit

React pour l'interface, PixiJS pour la cellule et la carte. Téléphone d'abord (375 px).

- Aucune règle de jeu ici : afficher l'état, envoyer des ordres, prévoir avec `core`.
- Tout élément lié à une mécanique passe par la table de déblocage. Pas de bouton grisé, pas d'onglet vide.
- Un écran = une idée. Zones tactiles de 44 px minimum.
- Couleurs, typographies, espacements : uniquement les jetons de design.
- Tous les textes viennent de `@o27/data`, en français et en anglais.
- Respecter « réduire les animations ». Joindre des captures téléphone et ordinateur à chaque PR visible.
